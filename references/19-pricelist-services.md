# PriceList + ServiceName (услуги Авито)

Проверено на автозагрузке «Деловые услуги → Бухгалтерия, финансы» (2026-09).  
Связано: [16-services-xlsx.md](16-services-xlsx.md), [18-autoload-rules-ru.md](18-autoload-rules-ru.md).

## Когда уточнять у пользователя (обязательно спросить)

Если чего-то нет в брифе / выгрузке — **не выдумывать**, спросить пакетом:

1. Есть ли **официальный прайс** (Google Doc / `sources/price-list.md`) с названиями и ценами?
2. Есть ли **активное объявление** в выгрузке автозагрузки — какой у него `PriceList` (эталон формата)?
3. Сколько позиций в карточке нужно: **1** / **~10** / до 50?
4. Какие позиции **исключить** (патент, нулевая отчётность, «работа с…» как условия)?
5. Какое название из **справочника Авито** должно быть **первым** (ServiceName) для каждого кластера title?
6. Можно ли маппить свободные названия прайса клиента → словарь Авито (да/нет; если нет — дать список словаря)?

Без (1) или (2) для услуг — **стоп** перед записью PriceList в xlsx.

## ServiceName / «Услуга» (критично)

Авито валидирует обязательный параметр **Услуга (ServiceName)**.  
На практике он берётся из **первой строки PriceList** (поле «название услуги» в прайсе).

| ✅ Делать | ❌ Не делать |
|----------|-------------|
| Первая строка = **имя из справочника** категории (как у живого объявления) | Первая строка = узкий оффер вроде только «Бюджетирование», если модерация/валидатор его не принимает как Услугу |
| Для бухгалтерии дефолт-lead: **`Аутсорсинг бухгалтерских услуг`** | Lead = свободный маркетинг («Финдиректор под ключ») |
| Дальше 2–10 позиций по теме кластера | Пустой PriceList, если в отчёте уже была ошибка ServiceName |

**Кейс:** title «Финдиректор…» + PriceList с первой строкой `Бюджетирование||…` → ошибка  
«Неправильно заполнен обязательный параметр — Услуга / ServiceName».  
Фикс: первая строка `Аутсорсинг бухгалтерских услуг||цена|Да|за услугу`, затем бюджетирование и остальное.

Ошибка в отчёте: `Правила: ServiceName / Услуга` → сразу проверить **первую** строку PriceList, не Title.

## Канонический формат строки

### Рекомендуемый (как у активного объявления в выгрузке)

```text
Аутсорсинг бухгалтерских услуг||3900|Да|за услугу
```

Поля: `Справочник||цена|Да|за услугу`  
Несколько услуг — **перенос строки** внутри ячейки (до **10** в пайплайне; лимит Авито до 50).

### Допустимый (документация шаблона)

```text
Изготовление кухни||30000||за услугу
```

(4-е поле пустое вместо `Да` — тоже встречается.)

### Запрещённый в этом пайплайне (ломает модерацию)

```text
Своя услуга|Ведение бухгалтерского учёта ИП и ООО|5000||за услугу
Своя услуга|Работа с дебиторской задолженностью|2000||за услугу
```

Ошибка Авито:  
«Проверьте значение параметра / Название услуги. Прайс-лист предназначен для **услуг**, а не **условий работы**».

Свободный текст после `Своя услуга|` часто читается как условия работы / не-услуга.

## Алгоритм сборки PriceList

```
Task Progress:
- [ ] Взять эталон PriceList с активного объявления (выгрузка)
- [ ] Загрузить прайс клиента (файл) — названия + цены
- [ ] Спросить / утвердить маппинг клиент → словарь Авито
- [ ] На кластер: 1-я строка = валидный ServiceName; ещё до 9 из прайса
- [ ] Уникальные имена словаря в ячейке (без дублей маппинга)
- [ ] Исключённые темы и «условия работы» выкинуть
- [ ] Активные строки: PriceList не менять без override
- [ ] Новые: записать; сверить первую строку = ServiceName
```

1. **Эталон формата** — скопировать синтаксис с активного `PriceList` в выгрузке.
2. **Источник цен** — `sources/price-list.md` или аналог клиента.
3. **Маппинг** клиентского названия → **точное** имя из фильтров/справочника Авито (бухгалтерия: «Ведение бухгалтерского учёта», «Бухгалтерские услуги для маркетплейсов», «Отчёт в Росстат»…).
4. **Порядок:**  
   - строка 1 → ServiceName (широкая услуга словаря);  
   - строки 2…N → тематика кластера (себестоимость, маркетплейсы, ВЭД…);  
   - цена 1-й строки ≈ `Price` карточки кластера.
5. **N по умолчанию = 10** (попросил пользователь) или 1 (как минимальный эталон). Уточнить, если не сказано.
6. **Не смешивать** в одной ячейке формат `Своя услуга|…` и справочник.

## Что считать «условиями работы» (не класть в PriceList)

Примеры брака / высокого риска:

- «Работа с дебиторской задолженностью»
- «Помощь с возвратом…» как процесс, не услуга словаря
- Длинные описания процессов вместо имени услуги
- Патент / нулевая отчётность — если в **Excluded themes** брифа

При сомнении — **спросить** или заменить на ближайшее имя словаря.

## Примеры маппинга (бухгалтерия)

| Из прайса клиента | В PriceList (словарь) |
|-------------------|------------------------|
| Бухгалтерское обслуживание на аутсорсинге | Аутсорсинг бухгалтерских услуг |
| Ведение бухгалтерского учёта ИП и ООО | Ведение бухгалтерского учёта |
| Бухгалтерия для Wildberries, Ozon… | Бухгалтерские услуги для маркетплейсов |
| Бюджетирование и финансовое планирование | Бюджетирование *(не первой строкой, если ServiceName падает)* |
| Расчёт себестоимости и составление калькуляции | Калькуляция |
| Подготовка и сдача отчётов в Росстат | Отчёт в Росстат |

Список словаря сверять с фильтрами категории на Авито / с `Спр-*` / с эталоном выгрузки — орфография важна (`учёта` / `расчетного`).

## Ошибки отчёта автозагрузки → действие

| Сообщение Авито | Что править |
|-----------------|-------------|
| Название услуги… прайс для услуг, не **условий работы** | Убрать `Своя услуга\|свободый текст`; только словарь `Имя\|\|цена\|Да\|за услугу` |
| Обязательный параметр **Услуга** / ServiceName | Первая строка PriceList = валидное имя словаря (часто «Аутсорсинг бухгалтерских услуг») |
| Старое время ошибки в отчёте (раньше текущей загрузки) | Перезалить актуальный xlsx; не править «вслепую» по устаревшему логу |

## Lock

- **Активные** (есть AvitoId): PriceList / Price не менять без явного запроса.
- **Новые:** можно и нужно править при ошибках модерации.

## Чеклист перед загрузкой

```
- [ ] Нет «Своя услуга|» в PriceList (если бриф не требует иначе и эталон без неё)
- [ ] Первая строка каждой новой = ServiceName из словаря
- [ ] ≤10 строк (или согласованное N); уникальные имена словаря
- [ ] Цены из прайса клиента; 1-я ≈ Price карточки
- [ ] Excluded themes не в прайсе
- [ ] Активные PriceList = как в выгрузке
- [ ] Бэкап xlsx перед правкой
```
