# Этап 0: Сбор брифа

Перед любым анализом собери данные. **Не додумывай** — спрашивай.

## Обязательные вопросы

Если в брифе нет ответа — задай вопрос:

1. **Услуга/товар** — что именно продаём (конкретно, не «услуги»).
2. **Главное преимущество** — одно ключевое отличие от конкурентов.
3. **Целевая аудитория** — кто покупает (если неизвестно — скажи, что определим на этапе 1).
4. **Регион/города** — список для колонки Address в CSV.
5. **Количество объявлений** — сколько строк нужно в итоговом файле (10 / 50 / 200 / 1000+); при нескольких категориях — **сплит** (например 1000 кухонь + 1000 шкафов).
6. **Цена** — если есть, укажи в брифе; отдельно: коридор ₽/п.м. и/или когортный разброс (100…100000).
7. **Исполнитель/бренд** — имя для подписи «Исполнитель: …» / название компании в карточке.
8. **Ограничения** — что нельзя писать, обещать, упоминать (антидетект vs соседний аккаунт).

## Желательные вопросы

9. Конкуренты или примеры объявлений (ссылки/скриншоты) / нужен ли **парсинг выдачи**.
10. Гарантии, сроки, бонусы.
11. Стиль общения (официальный / дружелюбный / экспертный).
12. Есть ли готовые фото или референсы; ImageUrls из текущего фида.
13. Нужны ли фото на выходе (этап 8); способ: **ImageUrls (Яндекс.Диск)** или **архив ZIP + ImageNames** (≤100 МБ вместе с Excel).
14. Система налогообложения, специализация (для услуг).
15. **Формат выдачи** — CSV / XLSX автозагрузки / оба.
16. **Длина Description** (часто 300–400 символов).
17. Телефон, почта; оставлять ли старые AvitoId / адреса.
18. Avito API `client_id`/`client_secret` — только для выгрузки, не в git.
19. **Excluded themes** — что **не** делать в этом фиде (напр. сезонная отчётность, аренда, закрытие ИП).
20. **Lock на активных** — какие поля не менять (Address, Category, Title, ImageUrls / ImageNames).

## Excluded themes (важно для услуг)

Зафиксируй в session явно:

```markdown
| Исключено | Причина |
|-----------|---------|
| Отчётность / сезонная сдача | не актуально сейчас |
| Аренда / недвижимость | другая ниша |
```

Не генерировать title, description, фото-сеты под excluded themes.

## Lock на активных объявлениях

По умолчанию для `AvitoStatus = Активно` из backup **не менять**:

- Address, Category, AvitoId, Title
- ImageUrls — **не менять** без явного запроса пользователя
- ImageNames / способ архива — тоже lock, если фото уже через ZIP

Override только если пользователь прямо просит обновить фото/URL/имена у активных.

## Правила intake

- Задавай вопросы **пакетом** (5–8 за раз), не по одному.
- Если бриф большой — сначала извлеки то, что есть, потом спроси только недостающее.
- Зафиксируй ответы в `output/session-{slug}.md` → секция «0. Бриф».
- Не переходи к этапу 1, пока нет минимума: услуга, регион/города, количество объявлений.

## Минимум для старта

| Поле | Обязательно |
|------|-------------|
| Услуга/товар | да |
| Города или регион | да |
| Количество объявлений | да |
| Преимущество/УТП | желательно |
| Цена | желательно |
