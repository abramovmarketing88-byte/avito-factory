# Экспорт / сборка XLSX автозагрузки Авито

Когда пользователь работает с **автозагрузкой**, финальный файл — Excel-шаблон Авито, не только CSV.

## Источник шаблона

- Чистый шаблон: `templates/osnovnoy.xlsx` (или имя из проекта)
- Не перезаписывай шаблон без бэкапа в `output/backups/`

## Структура листа категории

| Строки | Назначение |
|--------|------------|
| 1 | Путь категории (не трогать) |
| 2 | Заголовки колонок |
| 3 | Обязательность |
| 4 | Подсказки |
| **5+** | Данные объявлений |

Листы `Спр-*` и `Инструкция` не заполнять генератором.

## Типичные колонки (мебель)

Id, ListingFee/Package, AvitoId, ManagerName, ContactPhone, Title, Description, ImageUrls, ContactMethod, Category, Address, Price, вид товара/продажи, состояние, параметры категории, **За что цена**, Email, AvitoStatus, Company…

Точные индексы бери из строки 2 конкретного листа.

## Правила заполнения

- **Новые** объявления: AvitoId пустой; Id = стабильный uid (`al-k-1000`)
- **Старые** (если обновляем): не менять категорию и адрес без запроса; AvitoId сохранить
- После **scale до N строк:** не оставлять xlsx с пустыми NA-строками между объявлениями — см. [17-feed-clean.md](17-feed-clean.md) (compact)
- **Clean feed:** удалить листы чужих категорий (аренда, товары вне брифа) перед автозагрузкой
- Description: HTML `<p>…</p>`, длина по брифу (часто 300–400 plain)
- Price: целое; для «на заказ» часто **за погонный метр**
- ImageUrls: ротация существующих URL из шаблона/фида; не выдумывать битые ссылки
- AvitoStatus: `Активно` (если не просили иначе)
- Телефон / компания / почта — из брифа

## Несколько категорий

- Кухни → лист кухонь
- Шкафы-купе → лист «Шкафы и буфеты» (или актуальный лист шаблона)
- Не класть кухни в лист шкафов

## Выход

```
output/feeds/основной-{slug}-{n}.xlsx
output/feeds/avito-ads-{slug}-{date}.csv   # дубль Title/Description/Address
output/feeds/generate-report.json          # counts, price buckets, desc lens
```

## Сверка с research

Перед сдачей:
- [ ] ≥50% цен в рыночном коридоре (если был research)
- [ ] Title содержит ядро («на заказ») + 1 усилитель
- [ ] Дыры спроса представлены в выборке title
- [ ] Уникальность Title ≈ N
- [ ] Адресов уникальных достаточно для антидетекта
