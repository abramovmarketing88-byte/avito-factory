# XLSX автозагрузки — услуги (универсально)

Отличие от **товарной** мебели: другой лист шаблона, другие колонки, **PriceList**, цена «за услугу», не ₽/п.м.

## Когда применять

- Категория Авито: **Предложение услуг** (не «Мебель и интерьер»)
- Подтип из брифа: `ServiceType` / `ServiceSubtype` / `ServiceSubspecies` / `Speciality`
- Массовый фид 20–500+ строк одной услуги с кластерами title

## Intake (добавить к этапу 0)

| Поле | Пример (мебель) | Универсально |
|------|-----------------|--------------|
| Лист xlsx | `Производство, о-Изготовление из` | **из скачанного шаблона** категории |
| Строка данных | с **5-й** | всегда 5+ (1–4 — шапка) |
| Id / AvitoId | обновление активных | **активные:** Id+AvitoId из выгрузки; **новые:** новый Id, AvitoId **пусто** — см. [18-autoload-rules-ru.md](18-autoload-rules-ru.md) |
| Price | 25000–85000 lump | коридор из research, не п.м. |
| PriceList | см. [19-pricelist-services.md](19-pricelist-services.md) | **обязателен** для услуг; формат словаря + ServiceName |
| Description | 300–400 plain → HTML `<p>` | длина из брифа |
| ImageUrls | колонка из шаблона | после `avito-photos` |

**Колонки услуг (типичный шаблон 2026):**  
`Id, ListingFee, AvitoId, ContactPhone, ImageUrls, ImageNames, …, Title, Description, Address, ServiceType, …, PriceList, CompanyName, Email, …`

> Не хардкодить номера колонок между нишами — **прочитать row 2** шаблона и построить маппинг по имени поля.

## PriceList (Avito)

**Полные правила, ошибки модерации, маппинг и когда уточнять:**  
→ [19-pricelist-services.md](19-pricelist-services.md).

Кратко (бухгалтерия / деловые услуги, 2026):

```text
# ✅ Справочник (эталон с активного объявления)
Аутсорсинг бухгалтерских услуг||3900|Да|за услугу
Ведение бухгалтерского учёта||5000|Да|за услугу

# ❌ Не использовать в пайплайне (ошибка «не условий работы»)
Своя услуга|Свободное название из прайса|5000||за услугу
```

- **1-я строка** = параметр **Услуга / ServiceName** — только имя из словаря Авито.
- Дефолт: **~10** позиций из прайса клиента, замапленных на словарь; иначе уточнить N у пользователя.
- Не ставить первой узкую услугу вроде только «Бюджетирование», если валидатор требует широкую (кейс финдиректора).
- Перед записью: есть прайс клиента? есть эталон PriceList с активного? — если нет, **спросить**.

## Кластеры title (паттерн масштаба)

Для N объявлений — **не случайный shuffle**, а осмысленный микс:

```
main (1)     — главное активное, AvitoId если есть
cluster A    — ~30% title (напр. шкаф-купе)
cluster B    — ~30% (кухня)
cluster C    — ~20% (гарнитур / общее)
cluster D    — ~20% (общие / geo)
```

Формула title та же: `[ПРОДУCT/УСЛУГА] + [на заказ | под ключ] + [1 усилитель]`.

## Гео и адреса

- DaData / справочник: **уникальные** адреса по правилу брифа (МСК+МО, регион…)
- Не повторять один адрес на весь фид

## Чеклист services-xlsx

```
- [ ] Лист = из шаблона категории услуг
- [ ] Маппинг колонок по row 2, не по памяти
- [ ] PriceList: словарь `Имя||цена|Да|за услугу`; 1-я строка = ServiceName; см. [19-pricelist-services.md](19-pricelist-services.md)
- [ ] Нет `Своя услуга|свободный текст` без явного approve
- [ ] AvitoId **пусто** у новых; сохранён только у активных из выгрузки
- [ ] Id **не менялся** у активных; у новых — **уникальный** (скрипт merge)
- [ ] AvitoStatus / AvitoDateEnd **не заполнять** у новых
- [ ] Данные с 5-й строки, **без пустых дыр** (compact)
- [ ] Уникальные title + address
- [ ] Description 300–400 (или из брифа)
- [ ] Один лист в финальном файле (лишние удалить)
- [ ] Бэкап xlsx перед перезаписью
```
