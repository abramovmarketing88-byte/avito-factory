# Уникализация массовых объявлений

Цель: N объявлений без копипаста и без «одинаковой ленты» (антидетект мультиаккаунта / антиспам Авито).

## 1. Модельные имена (серии)

Придумай банк **80–120+** имён на категорию.

Примеры кухонь: Елена, Виктория, Дубай, Амадея, Камень, Милана, Тоскана, Графит…  
Примеры шкафов-купе: Норд, Сити, Слайд, Гласс, Миррор, Лайн, Профиль…

В title: `Кухня {модель} на заказ`, `Шкаф-купе {модель} на заказ`.  
В тексте: «серия / модель «{имя}»».

Не использовать имена, которые ломают формулу (напр. модель «Купе» → «Шкаф-купе Купе»).

## 2. Характеристики

Ротация параметров категории:
- Кухни: форма (прямая/угловая/П), сценарий (студия, 2 м, модульная), фасад, цвет
- Шкафы: створки, зеркало, встроенный, ниша, спальня/прихожая

Один параметр = усилитель в title (не сваливать всё в одну строку).

## 3. Адреса

Список **десятков–сотен** реальных/правдоподобных адресов по гео-правилу брифа  
(пример: Москва + города МО в ~20 км от МКАД: Химки, Мытищи, Балашиха, Одинцово…).

Не ставить один адрес на все строки.

## 4. Цены (когорты + рынок)

Если есть research:
- **~50%** строк в коридоре медианы рынка ₽/п.м. (кухни Москва ≈ 12–25 тыс)
- Часть — агрессивный вход / премиум
- Хвосты **100…100000** (или как просил пользователь) — чтобы попадали разные когорты выдачи

`За что цена` согласовать с рынком (часто «за погонный метр»).

## 5. Тексты

- Спинтекст level 4 **или** композиция блоков (hook + mid + trust + geo + CTA)
- Hash Description → без дублей
- Факты бренда фиксированы; меняются формулировки и модель/параметры

## 6. Антидетект vs соседний аккаунт

Зафиксируй в брифе запреты, например:
- чужие бренд-фразы / «идеальный порядок»
- одинаковые эмодзи-шапки
- копирование title конкурента 1-в-1
- та же структура длинного HTML

Стиль своего бренда: короче, другие УТП, другие ключи.

## 7. Проверки после генерации

```
unique titles ≈ N
desc length in range
price_buckets printed
unique addresses ≥ порог
category sheets correct
```
