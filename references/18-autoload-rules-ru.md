# Автозагрузка Авито — правила (услуги + загрузка)

Сжатая выжимка из официальных инструкций Авито. Полные тексты: `briefs/avito-autoload-upload.md`, `briefs/avito-services-params.md`.

## Структура XLSX

| Строки Excel | Содержимое |
|--------------|------------|
| 1 | Путь категории — **не менять** |
| 2 | Заголовки колонок (Id, Title, …) |
| 3 | Обязательность |
| 4 | Подсказки |
| **5+** | Данные объявлений — **без пустых строк между** |

- Не добавлять листы вручную
- Не удалять `Инструкция` и `Спр-*` для оставшихся категорий
- Все ячейки — **текстовый формат**
- Несколько значений в параметре — через ` | ` (пробел-вертикальная черта-пробел)

## Id и AvitoId (критично)

| Параметр | Новое объявление | Уже на Авито (активное) |
|----------|------------------|-------------------------|
| **Id** | Придумать **новый уникальный** (≤100 символов) | **Не менять** |
| **AvitoId** | **Пусто** — присвоит Авито | Заполнить номер с сайта/выгрузки |

- Id не должны повторяться в файле
- При смене Id без AvitoId Авито создаст **новую** карточку (риск дубля)
- При редактировании активных: **не трогать** Id и AvitoId

**Не заполнять:** `AvitoStatus`, `AvitoDateEnd` — управляет Авито.

## База для merge-фида

1. Скачать файл **только с активными** из «Автозагрузка → Создать файл»
2. Новые строки **добавить в конец** data-листа (после активных)
3. Активным — Id + AvitoId из выгрузки; новым — свежий Id, AvitoId пустой
4. Скрипт: `scripts/merge_active_and_new_feed.py`

## Фото

Два способа Авито (не смешивать в одной строке):

### ImageUrls (дефолт пайплайна)

- HTTP/HTTPS или **приватная ссылка Яндекс.Диска** (cloud-api)
- До **10** фото: `url1 | url2 | …`
- Если указан **ImageUrls** → **ImageNames пусто**
- Детали: скилл **`avito-photos`**, режимы A/C/D

### Архив + ImageNames (режим F)

По инструкции Авито:

1. Подготовить фото; продумать **названия или нумерацию**
2. Сложить в архив: **без папки и без разбиения по папкам внутри** (плоский ZIP)
3. В **ImageNames** — имя с расширением, напр. `Фото_1.jpg`; несколько — `|` или перевод строки (` | ` в пайплайне)
4. Загрузить **архив вместе с Excel**
5. **Архив + Excel ≤ 100 МБ**

- ImageUrls при этом **пусто**
- Полные правила: скилл **`avito-photos`**, режим **F**, файл `references/archive-upload.md`
- Массовые фиды обычно не влезают в 100 МБ → оставаться на ImageUrls

## Услуги — обязательные поля (бухгалтерия)

- `Category` = Предложение услуг
- `ServiceType` = Деловые услуги
- `ServiceSubtype` = Бухгалтерия, финансы
- `Title` ≤100 символов, без цены и контактов в названии
- `Description` ≤7500, HTML `<p><ul><li>…` по тарифу
- `Address` — полный адрес до 256 символов
- `Place`, `Consultations`, `WorkWithContract`, `Prepayment` — обязательны
- `PriceList` — рекомендуется (до 50 услуг в ячейке, построчно в Excel)

## ListingFee

- `Package` (по умолчанию) — из пакета размещения
- `PackageBBL`, `BBL` — по правилам тарифа

## Clean перед загрузкой

См. [17-feed-clean.md](17-feed-clean.md):

- Удалить чужие листы (аренда, товары)
- Compact: header 1–4 + только строки с Title
- Pre-launch: data с **5-й строки**, Id заполнен, новые без AvitoId

## Ошибка «Не найдены объявления / Id не заполнен»

Частые причины:

1. Пустые строки 5–9 перед первым Id (после scale без compact)
2. Все AvitoId заполнены у «новых» — Авито не создаёт карточки
3. Сломанная шапка (строки 1–4) после pandas write

## Гео (Address) — MSK…MSK+2

Зона: **европейская часть до MSK+2**. Исключить: Крым, ДНР/ЛНР, Запорожье, Херсон, Дальний Восток, Сибирь (Новосибирск, Омск, Красноярск и т.п.).

| Тип объявления | Address |
|----------------|---------|
| **Активное** (есть AvitoId) | Менять **только если** адрес не проходит фильтр |
| **Новое** (AvitoId пуст) | Назначить из пула: ~60% Москва/МО, ~20% СПб/ЛО, ~20% MSK+1/+2 |

- Не добавлять в Title/Description отдельные фразы «мы в Москве» — оставить «удалённо по России»
- Не использовать тему **отчётность / до июля** — заменить Title или удалить строку
- Пул адресов: `output/data/geo-address-pool.json`
- Скрипт: `scripts/fix_geo_addresses.py` → бэкап `output/backups/*-before-geo-*.xlsx`
- QA: `scripts/qa_feed.py` → `output/reports/geo-fix-report.json`
