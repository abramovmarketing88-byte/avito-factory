# Этап 0.5: Конкурентный research выдачи Авито

Делай **отдельно по каждой категории** (кухни ≠ шкафы-купе). Не смешивай выводы title/цен.

## Когда обязательно

- N ≥ 200 объявлений
- Пользователь просит «как у конкурентов» / «по парсингу» / canvas
- Смена ниши или города

## Что снять

1. Поиск Авито: запрос ядра («кухонный гарнитур», «шкаф-купе на заказ») + город
2. **4–10 страниц** карточек (title, цена, продавец, бейджи, сниппеты)
3. Блок **«Популярные запросы»** внизу страницы
4. Опционально: клик по 1–2 хвостам (студия / модульный) для доп. ключей

## Куда сохранить

```
output/research/{category}-{geo}/
  README.md
  avito-title-methodology-{category}.md
  avito-competitor-analysis-{category}-{geo}.md
  avito-popular-keywords-{category}.txt
  titles-{category}-avito-competitors.txt
  avito-{category}-{geo}-stats.json
```

## Что посчитать в stats.json

- `priceTypes`: за п.м. / за всё
- `pmPriceRub`: min / median / avg / max
- `promos`: Рассрочка, Продвинуто, Доставка, −10%, −15%…
- `titleKeywordHits`: на заказ, размер, от производителя, угловая…
- `textHooks`: столешница, подарок, 3d, расчёт, фабрика…
- `topSellers`: кто держит пачку объявлений
- `recommendedTitles`, `strongListingExamples`

## Формула title (типичная для «на заказ»)

```
[ПРОДУКТ] + [на заказ] + [1 усилитель]
```

4–7 слов. Усилитель: размер | производитель | форма | срок | под ключ | сценарий | модель.

## Дыры спроса

Ключи из «Популярных запросов», которых **мало в топе** текущего «на заказ» — приоритет в матрицу title (пример кухонь Москва: маленький, в студию, 2/4 метра, модульный).

## Canvas (рекомендуется)

Собери `.canvas.tsx` в `canvases/` проекта Cursor:
- медиана ₽/п.м., доли типов цены
- частотность ключей / промо
- таблица дыр спроса
- топ продавцов и сильные примеры
- блок «что заложено в фид»

Импорт только из `cursor/canvas`. Данные inline.

## Как применять к фиду

После research обнови генератор/спинтекст:
1. Коридор цен ≈ медиана рынка (±)
2. Title-формула + дыры
3. CTA и крючки из топ textHooks
4. Не копировать дословно чужие title 1-в-1 (антидетект)
